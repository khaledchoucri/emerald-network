# Agent entry point

Follow the repository ground rules in `CLAUDE.md`, including keeping `upstream/`
read-only and keeping extracted game assets out of commits and shared deliveries.

For image generation or asset coordination, read `docs/asset-workflow/README.md`
and `docs/asset-workflow/QUEUE.md` first. The shared workflow assigns design and
integration to the implementation agent and image production to Codex. It does
not authorize unrelated code changes or automatically start queued requests.

Use the existing checkout. Read current files and preserve other agents' work.
Do not assume another agent shares this machine, local paths, or chat history.
